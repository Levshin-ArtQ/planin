# Planin

Личный день на iPhone. Список, часы, покупки и привычки. Данные живут только в этом браузере (IndexedDB). Сеть нужна, чтобы открыть страницу, не чтобы хранить день.

Версия **1.0.0**.

## День

Свайп по листу — соседний день. Строка пишется снизу, расписание остаётся на экране.

Три вида дел:

- **без времени** — в том порядке, в каком записаны, пока не перетащишь
- **окно** — успеть с такого-то до такого-то (`с 12 до 14`, `до 16`)
- **час** — точка в дне (`14:30`, `в 14`, `8 вечера`)

Полоса **11–20** по будням подсвечивает рабочие часы. Нажатие раскрывает день по часам. Само раскрытие включается, когда на день уже три дела со временем.

Сделанное остаётся на месте. В настройках оно тускнеет, зачёркивается или и то и то. Повторный свайп влево возвращает строку в день.

## Перенос

Свайп вправо — на завтра. Вправо и вниз — глубже: завтра, послезавтра, +3 … +7, +14. Долгое нажатие открывает меню.

У привычки тот же жест **сдвигает ритм**, а не копит пропуск. «Раз в 2–3» после выполнения считается от дня, когда сделал. «Каждый пн», перенесённый на день, становится следующим днём недели.

## Список покупок

Он ниже задач и остаётся раскрытым, пока его не свернёшь. Enter сразу готовит следующую строку. «купить молоко», «забрать озон». Купленное остаётся на своём месте в списке.

## Фразы

Та же строка разбирает клавиатуру и голос.

| Фраза | Куда ложится |
|---|---|
| `написать отчёт` | в этот день, без времени |
| `завтра в 14 врач` | завтра, на 14:00 |
| `с 12 до 14 обед` | окно |
| `до 16 отчёт` | успеть до 16 |
| `через 3 сдать книгу` | через три дня |
| `пн планёрка` | ближайший понедельник |
| `купить молоко` | в список |
| `привычка мазь раз в 2-3 вечером` | привычка, вечер, окно 2–3 дня |
| `каждый пн спорт` | раз в неделю |

На iPhone диктовка — микрофон на клавиатуре: фраза падает в строку и разбирается по этим словам. Если браузер умеет слушать сам, кнопка справа делает то же самое.

Слова собраны в `js/parse.js`. Новый жест или новое слово добавляется туда, а не в разрозненные проверки.

## Жесты

- тап по дате — сегодня, долгое нажатие — календарь
- лист влево / вправо — день
- строка влево или двойной тап — выполнить, строка остаётся
- стереть можно только через «убрать»
- строка вправо — на завтра, вправо и вниз — на сколько дней
- долгое нажатие — меню
- полоса часов раскрывает день, «к списку» закреплена снизу
- `]` — на завтра, `d` и цифра — на столько дней, стрелки — дни и строки

## Данные

Экспорт и вгрузка — в настройках. Файл `planin-….json`. На iPhone экспорт открывает системное «поделиться». Замена из файла отменяется кнопкой «отмена».

Чужой JSON, не из Planin, не принимается.

## Запуск

```bash
cd listok
npm test
npm start   # http://localhost:8771
```

iPhone: Safari → Поделиться → На экран «Домой».

Vercel: корень `listok/`, Framework **Other**, без install и build. `vercel.json` уже лежит в папке.
